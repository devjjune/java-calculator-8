# java-calculator-precourse

## 🔧 구현할 기능 목록

1. 입력값을 받아 검증
- 사용자로부터 문자열을 입력받는다.

2. 커스텀 구분자 추출
- 입력 문자열이 `//`로 시작하는 경우, `//`와 `\n` 사이의 문자열을 커스텀 구분자로 인식한다.
- 커스텀 구분자가 없는 경우, 기본 구분자 `,`와 `:`를 사용한다.

3. 입력 문자열 분리
- 구분자를 기준으로 입력 문자열의 숫자 부분을 분리한다.
- 입력값이 '구분자와 양수로 구성된 문자열'이 아닌 경우, `IllegalArgumentException`을 발생시킨
  후 애플리케이션을 종료시킨다.

4. 숫자 변환 및 합산
- 자른 문자열을 숫자로 변환 후 모두 더한다.
